# Decisions

One short file per approved decision. A decision is only here if the author approved it.

**Format:** title, `Status` (Approved, Superseded by NNNN, or Proposed), date, then the decision, the reason, and what it replaced. Keep each file to a screen.

**Superseding:** do not delete the old file. Change its status to `Superseded by NNNN` and link forward in the same commit.

**Authority:** the code says what exists. These files say what was decided and why. If they disagree, say so in `HANDOFF.md` and ask.
